# distributable-suite-native

Native extension distribution for PY-CAN-PKG-010 wheel tags.

- Pure wheel tag for other distributions: `py3-none-any`
- Native CPython tag: `cp314-cp314-linux_x86_64` (built on this platform)
- Stable ABI tag: `abi3` (model via limited API, not built but documented)
- Platform tags: `manylinux_2_34_x86_64` would apply for manylinux builds
