# roslyn-components coverage

The default build context is `net10.0` on SDK 10.0.110 with CoreCLR 10.0.10, `ubuntu.26.04-x64`.
The `netstandard2.0` Roslyn component context (generator, analyzer, suppressor) is made available
by the vendored `NETStandard.Library` 2.0.3 reference pack at `vendor/NETStandard.Library.2.0.3.nupkg`
(provenance at `vendor/README.md`, `vendor/licenses/`) plus the Roslyn API packages.
The project has no test source. The generator emits its compilation units in-process during the
consumer build; no committed generated output and no `generate` task are required.
