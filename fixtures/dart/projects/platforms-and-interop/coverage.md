## Declared build contexts

- `vm-jit` (default): `dart run bin/vm_main.dart`, `dart run bin/mirrors_main.dart`, `dart analyze`.
- `native-aot`: `dart compile exe -o build/native_aot_main bin/native_aot_main.dart`, then run the compiled binary.
- `js`: `dart compile js -o build/js_main.js bin/js_main.dart`.
- `wasm`: `dart compile wasm -o build/wasm_main.wasm bin/wasm_main.dart`.
